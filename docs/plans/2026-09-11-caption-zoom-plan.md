# 강조 자막·줌 구현 계획

상세 설계 승인 후 실행한다. writing-plans 스킬은 설치되지 않아 기존 docs/plans 형식으로 작성한다.

1. 원본 시간 기반 강조 계약, v9 저장과 구버전 마이그레이션, stale 검증을 구현한다.
2. 실제 Go 렌더러에 프레임 시간 기반 줌과 문장별 강조 자막을 연결한다.
3. 문장 선택/강조 설정/실행 취소 및 AI 선택 제안을 편집기에 연결한다.
4. 독립 예상값 기반 JS/Go 테스트, 실제 FFmpeg 출력, 브라우저 핵심 흐름을 검사한다.
5. 결과와 미실행 항목을 별도 기록한다. 실제 한국어 녹화본 및 경쟁 도구 비교는 자료/실행 근거 없이 통과 처리하지 않는다.

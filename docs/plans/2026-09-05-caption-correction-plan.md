# AI 자막 교정 구현·검증 계약

기존 승인된 AI 선택 연결 및 C07/C08 계획을 구현한다. 원문 전체 자동 덮어쓰기, 제안만 표시, 제안별 선택 적용 중 **제안별 선택 적용**을 사용한다. 속도와 문구 보존을 함께 확인할 수 있고 기존 자막 실행 취소를 재사용할 수 있다.

- 현재 자막 또는 현재부터 최대 20개/총 4,000자의 연속 자막을 명시적으로 선택한다. 범위와 보낼 문구를 요청 전에 보여준다. 이번 요청에 참고할 용어를 입력할 수 있다.
- 공급자는 기존 연결 UI의 Ollama·OpenAI API·Claude API·Claude Code를 공유한다. 수동 채팅 복사/JSON 가져오기도 같은 검증을 거친다. 수동 전달을 ChatGPT MCP 통합 완료로 표시하지 않는다.
- 요청마다 새 ID를 만들고 ID·문구·용어·교정 지시만 전달한다. 원본 경로·파일명·시각·음성·영상·인증 정보는 프롬프트에 넣지 않는다.
- 응답은 요청 ID와 변경 목록(id, before, after, reason)만 허용한다. 다른 요청·알 수 없는 자막·중복 ID·원문 불일치·빈 수정·시각/실행 명령·숫자 변경은 거부한다. 부정 표현 변화는 별도 검토 표시한다. 이 규칙이 의미 보존 전체를 보장하지는 않는다.
- 모든 제안은 기본 미선택이다. 원문·제안·이유를 보고 선택한 변경만 한 번 적용한다. 실제 적용 직전에도 원문과 요청 대상을 재검증한다. 자막 시각은 그대로이며 변경된 문장의 컷 검토는 무효화한다. undo/redo·프로젝트·SRT·MP4는 기존 자막 경로를 따른다.
- 공급자/요청 문구/대상 변경·닫기·취소는 이전 응답을 폐기한다. 자동 재시도·다른 공급자 전환·자동 적용은 없다. 연결 상태와 실제 검증된 응답은 구분한다.
- 이번 요청의 용어 입력은 일시적이다. 프로젝트 용어 사전의 저장·재사용은 별도 남은 범위로 기록한다.

먼저 고정 오타·숫자·부정어·사전 입력으로 도메인 검사를 작성한다. 각 공급자 요청/오류/취소/오래된 응답 및 실제 모의 CLI 프로세스를 확인한다. 두 앱에서 수동·모의 연결의 비교/선택/취소/undo·SRT/MP4를 실행한다. 실제 인증된 모델의 교정 품질·요금·한국어 정확도는 이 시험으로 대체하지 않는다.

연결 계약은 공식 [OpenAI 구조화 출력](https://developers.openai.com/api/docs/guides/structured-outputs), [Ollama](https://docs.ollama.com/capabilities/structured-outputs), [Claude](https://platform.claude.com/docs/en/build-with-claude/structured-outputs)을 확인했다. 의미 검증은 JSON 스키마 밖의 앱 도메인 검사로 수행한다.

# 전사 끝 경계 복구·검토 계획

60분 실제 Whisper 시험에서 580개 중 마지막 자막이 3,596.240~3,600.240초로 반환되어 전사 전체가 실패했다. 동일한 CLI 설정으로 재현했으며 입력 WAV는 정확히 3,600초다. 원시 결과는 `test-output/transcription-end-diagnostic/raw.json`에 보존했다.

고정 엔진 소스는 30초 패딩 및 타임스탬프 토큰으로 구간을 생성한다. 따라서 원본 끝을 가로지르는 마지막 창의 구간을 가져오는 과정에서 처리한다. 일반 프로젝트·렌더 시각 검증을 느슨하게 만들지 않는다. [고정 whisper.cpp 소스](https://github.com/ggml-org/whisper.cpp/blob/371b5a7561823ab2bb32142d2751e35e7534727b/src/whisper.cpp)를 참고한다.

- 시작이 원본 안에 있고 마지막 30초 창 안이며 끝 초과와 구간 자체 길이가 모두 30초 이하인 구간만 원본 끝으로 맞춘다. 원본 밖에서 시작하거나 큰 시각 오류·겹침·잘못된 자료는 계속 거부한다.
- 원래 모델 끝 시각을 `timingWarning`으로 보존한다. 문구를 임의로 삭제·치환하거나 검토 완료로 처리하지 않는다.
- 끝 경계가 조정된 자막은 목록과 편집 창에서 검토 필요로 표시한다. 기존 컷 검토와 같은 확인 이력을 사용하되 원인과 안내를 구분한다. 실제 원본의 끝 문구를 확인·수정한 후 명시적으로 확인한다.
- 미검토 자막이 출력에 남아 있으면 SRT·자막 포함 미리보기/MP4를 거부한다. 원본 청취용 VTT는 별도로 표시하여 검토를 돕는다. 검토가 저장·실행 취소·AI 교정·컷 변경에서 정확히 유지/무효화되어야 한다.
- 프로젝트 v7은 검토 정보를 보존한다. v1~v6을 이전하며 기존 컷 검토 키는 그대로 유효하다. 구버전 앱이 경고를 버리고 출력하지 않도록 v7 파일은 구버전에서 열 수 없게 한다.

실제 원시 출력 발췌로 도메인 회귀를 고정한다. 검토 전 출력 차단, 검토/문구 변경/취소/저장 왕복, 두 앱의 실제 SRT·MP4를 검사한다. 그 뒤 새 빌드에서 10분·60분 성능을 다시 측정한다. 끝 시각 조정은 한국어 인식 정확도나 잘린 단어 복원을 보장하지 않는다.

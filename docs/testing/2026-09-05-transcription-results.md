# 로컬 전사·자막 편집 실행 기록

이 문서는 v3 전사 단계의 기록이다. 이후 추가한 디자인·v4 저장·MP4 합성은 [후속 실행 기록](2026-09-05-caption-rendering-results.md)을 따른다. 아래 미구현 표시는 이 단계 실행 당시의 상태다.

실행일: 2026-09-05. 기준 커밋 `47373e5` 이후 이 문서와 함께 추가한 전사 변경을 작업 트리에서 검증했다. 정식 MVP 전체 통과 또는 실제 사람 녹음의 한국어 정확도 통과를 뜻하지 않는다.

## 구현한 사용자 흐름

브라우저·Mac 앱에서 영상 선택 → 전사 언어·채널 선택 → 실제 Whisper 추론 → 원본 자막 재생 → 문구·시각 수정 → 컷 경계 검토 → 편집 시간축 SRT 저장 → 프로젝트 v3 복원까지 연결했다. 자막 삭제·실행 취소·다시 실행을 지원한다. 적용 전 입력을 이동/닫기로 잃지 않도록 확인하고, 적용한 수정은 프로젝트에 저장한다.

자막은 원본 시각에 보관하며 최종 SRT의 시간축은 실제 MP4와 같은 프레임 목록·유지 구간으로 계산한다. 부분 삭제된 문장은 자동 복제하지 않고 검토를 요구한다. 확인한 문구는 남은 시간에 한 번 표시한다. 문구·시각·컷이 달라지면 기존 검토를 재사용하지 않는다. 완전히 삭제된 문장의 자막은 출력에서 제외하고 원본 컷을 복원하면 다시 표시한다.

원본 플레이어의 기본 자막 표시는 동작한다. **자막 디자인의 MP4 합성·AI 자동 교정·효과음은 아직 구현하지 않았다.** SRT 저장을 그 기능의 완료로 처리하지 않는다. 현재 영상 출력에 자막이 포함되지 않는다는 내용을 화면에 표시한다.

## 엔진과 패키지

- whisper.cpp 소스: `371b5a7561823ab2bb32142d2751e35e7534727b` (`b4938`). CLI 버전 출력은 `1.9.3-dev`다.
- 소스 아카이브 SHA-256: `89051d8fca516a3ad1f5c2f8f9d2fccb089afbaec338fca3f8731999babc6f81`.
- 다국어 Whisper small: 487,601,967 bytes, SHA-256 `1be3a9b2063867b937e64e2ec7483364a79917e157fa98c5d94b5c1fffea987b`.
- Apple Silicon CPU·Accelerate, 스레드 4개, Metal 꺼짐. 선택 채널을 16kHz 16bit mono WAV로 변환한다. 원본/출력 음량은 바꾸지 않는다.
- 모델 파일은 매 전사 전에 해시를 검사한다. 파일 크기·CLI 버전 확인과 실제 추론 성공은 별개다. 손상/취소 시 현재 컷·자막은 보존하고 클라우드로 대체하지 않는다.
- `npm run setup:transcription`은 프로젝트 내부 도구와 모델을 준비한다. 모델은 Git에서 제외하고 Mac 패키지의 `Resources/transcription`에 실행 파일·라이선스와 함께 포함한다.
- 현재 패키지는 약 902MiB. FFmpeg/ffprobe는 여전히 로컬 설치가 필요하며 서명·공증 및 다른 OS 지원은 검증하지 않았다.

출처와 실행 파일 해시: [모델 명세](../../assets/models/whisper-small.json). 다운로드·재빌드·이미 받은 모델의 해시 확인 후 재사용을 실행했다. 모델 다운로드 중 사용자 취소/설치 복구의 전체 시나리오는 미검증이다.

## 실제 모델 결과와 한계

시험 음원은 macOS 한국어 TTS로 직접 만든 ‘작은 목소리도 남겨 주세요. 긴 무음만 줄이면 됩니다.’를 두 번 배치한 17.7초 자료다. 작은 음량·오른쪽 채널만 발화·44.1kHz 반대 위상과 시작 PTS +3초를 각각 실제 모델로 실행했다. 원본 해시는 처리 전후 동일했고 전사는 원본 시간 범위 안에 있었다.

첫 실제 결과에는 **‘무음 → 부분’ 오인식**이 있었다. 첫 자막 시각도 발화 시작보다 앞선 0초에서 시작하는 등 정밀하지 않았다. UI 시험에서는 문구와 원본 시각을 직접 교정하고 컷 경계를 확인한 뒤 저장했다. 결과 문자열이 생겼다는 이유로 T02 정확도·자막 시각 목표를 통과 처리하지 않는다.

양쪽 앱의 교정 후 SRT는 동일했다:

- 첫 자막: 원본 1.100~6.700초 → 편집본 0.167~5.467초.
- 두 번째: 원본 10.500~16.050초 → 편집본 5.933~11.217초.

이 수치는 해당 TTS fixture와 VAD 컷의 결과이며 일반적인 편집 성능 수치가 아니다. 독립 고정 정답 테스트에서는 원본 `[5,6.2)`와 앞선 2초 컷을 SRT `[3,4.2)`로 확인했다. 부분 삭제 문장의 검토, 문구 수정 후 검토 무효화, 전체 삭제, 컷 복원도 검사했다.

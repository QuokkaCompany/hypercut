# HyperCut Claude Code 연결 검증 — 2026-09-05

## 판정과 범위

Claude Code의 기존 구독 로그인으로 자연어 무음 설정을 제안받는 실험 연결을 추가했다. 실제 CLI의 설치·로그인 상태를 확인했고, 모의 CLI를 사용한 프로세스·API·브라우저·Mac 앱 검사는 통과했다. **인증된 모델 요청은 0회이며 실제 모델 응답 품질과 사용량 검증은 NOT_RUN이다.** A07 또는 G4 전체 통과로 처리하지 않는다.

기준 소스는 `bb7c168` 이후 이 보고서와 같은 변경 묶음이다. Apple M4 Max / macOS arm64 / Node 24.14.1 / Electron 44.2.0 / FFmpeg 8.1.1 환경에서 실행했다. 테스트 파일 선택·저장 경로는 자동화가 지정했다. 외부 사용자 영상과 계정 정보는 시험 자료로 사용하지 않았다.

## 동작

- AI 메뉴에서 **Claude Code — 기존 구독 로그인**과 모델 이름을 선택한다. 실제 응답 전에는 설정 저장과 로그인 확인만 표시한다.
- 설치·필수 옵션·구독 인증 여부를 확인한다. API 키 방식이나 다른 공급자 인증이면 구독 연결 요청을 허용하지 않는다.
- 요청문과 현재 네 가지 설정만 전달하고, 허용된 스키마와 수치 범위를 통과한 제안만 보여준다. 사용자가 적용하기 전에는 편집 설정이 바뀌지 않는다.
- 사용 모델과 입력/출력 토큰을 응답에서 확인할 수 있으면 표시한다. 없는 사용량은 0으로 만들지 않고 확인 불가로 표시한다. 실제 요금이나 구독 잔여량을 추정하지 않는다.
- 취소·시간 초과·앱 종료 시 실행 중인 CLI를 종료한다. 실패한 AI 요청 이후에도 로컬 분석·내보내기를 사용할 수 있다.

## 실패 경로와 구현 확인

- 프로세스 입력의 셸 특수문자가 실행되지 않고 문자열로 전달되며, 바이트 단위로 나뉜 한국어 UTF-8 응답을 복구했다.
- 256KiB를 넘는 출력, 잘못된 JSON, 불완전한 결과, 범위 밖 설정은 오류로 처리했다. 공급자의 원문 오류·세션 ID·계정 식별자를 UI에 그대로 노출하지 않는다.
- 취소 시 실제 POSIX 프로세스 그룹의 SIGTERM을 무시하는 자손까지 종료했다. 서버 종료 또한 AI 작업 정리를 기다린다. Windows 프로세스 트리 종료는 실행 검증하지 않았다.
- 브라우저에서 로그인 확인 요청을 보류한 상태로 연결 설정을 저장한 뒤 응답을 해제했다. 상태 확인이 끝나고 재확인·제안 버튼을 계속 사용할 수 있었다. 상태 확인과 제안 요청의 오래된 응답 판정을 분리했다.
- 모의 공급자 오류와 취소 후 예전 제안을 남기지 않으며, 실제 편집 화면의 설정을 자동 변경하지 않는다.

CLI 실행은 임시 작업 디렉터리, 표준 입력, `shell:false`를 사용한다. 상속 환경의 API 키·인증 토큰·공급자 우회 주소·NODE_OPTIONS를 전달하지 않는다. 기존 로그인에 필요한 HOME은 그대로 보존한다. `--safe-mode`, 빈 built-in 도구 목록, 빈 MCP 설정, 세션 저장 끄기, 무인 권한 거절 옵션을 사용한다. 관리자 정책이 적용하는 훅 등까지 HyperCut이 제거한다고 보장하지 않는다. [CLI 공식 옵션](https://code.claude.com/docs/en/cli-reference).

2026-09-05에 확인한 공식 지원 문서 상단의 6월 15일 업데이트는 SDK·`claude -p`·서드파티 앱 사용이 계속 구독 한도에서 차감된다고 안내한다. 하단에 보존된 과거 월별 크레딧 변경안은 적용 정책으로 사용하지 않았다. [구독 사용 안내](https://support.claude.com/en/articles/15036540-use-the-claude-agent-sdk-with-your-claude-plan). 실제 계정의 한도·추가 사용 설정·요금은 별도로 확인해야 하며 여기서 측정하지 않았다.

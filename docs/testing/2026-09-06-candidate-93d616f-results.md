# 전사 복구 후보의 기본 무음 편집 검증

2026-09-06. `93d616f`의 브라우저 번들과 패키징한 Mac 앱을 대상으로 한 기록이다. [전사 준비 상태·복구 검증](2026-09-06-transcription-readiness-results.md) 이후 제품을 고정했고, [장시간 계획](../plans/2026-09-06-thousand-cut-performance-plan.md)에 앞서 짧은 기본 경로를 확인했다. 실제 한국어 품질과 전체 MVP의 완료 판정은 아니다.

## 60초 입력의 두 앱·캐시 조건

warm/cold × Chrome/Mac × 2회, **총 8회와 취소·재시도 4조건을 완료·감사**했다. [실행 요약과 원본 감사](results/2026-09-06-candidate-93d616f-threshold-smoke.json)에 실제 보고서·출력·소스 해시와 원시 기록 위치를 보관했다.

| 입력 파일 조건 | 실행 수 | 최대 분석 시간 | 최대 출력 시간 | 최대 합산 RSS | 조작군 최대 p95 |
| --- | --- | --- | --- | --- | --- |
| warm | 4 | 1.361초 | 3.511초 | 1.627GiB | 67.24ms |
| cold | 4 | 1.408초 | 3.494초 | 1.625GiB | 67.08ms |

Apple M4 Max·36GiB·AC 전원, Node 24.14.1·FFmpeg 8.1.1에서 측정했다. 60초·1080p·30fps H.264/AAC 합성 영상에 -40dBFS, 최소 500ms, 말 앞 100ms·뒤 150ms를 적용했으며 말소리 보호는 껐다. 입력은 사람의 말이 아닌 주기적인 톤과 영상 표식이다.

입력 1,207,118바이트의 74페이지 중 warm은 매번 74페이지, cold는 0페이지가 파일 선택 직전에 상주했다. 이는 선택한 입력 파일의 캐시 조건이며 OS 전체나 앱 실행 파일·업로드 사본의 캐시 조건은 아니다. 캐시 사본 준비를 제외한 실제 가져오기·분석 시간과 앱 내부 출력 검증을 포함한 내보내기 시간을 보고한다.

모든 결과의 16개 컷, 출력 1,448프레임·PTS, 6개 A/V 표식 쌍, 전체 프로젝트를 검사했다. 출력 길이는 약 48.267초이며 MP4 SHA-256은 8회 모두 `f6a0ca24ac51507d5eb61cec94b673cc3f96e3d9790651b0d3a9195e5147a7f1`였다. 전체 픽셀 비교를 새로 실행했다는 뜻은 아니다. cold 결과는 같은 후보의 warm 결과와 분석·프로젝트·출력을 비교했다. warm의 첫 자기 비교는 내부 일관성 확인이며 독립 정답 증거를 대신하지 않는다.

취소 직전 상태는 네 조건 모두 `running`·`작업 준비`·진행률 0이었다. 취소 표시 최대 0.81ms, 재시도 가능한 상태까지 최대 311.86ms였고 각각 두 번째 반복을 완료했다. 이를 디코딩 중간 취소의 증거로 확대하지 않는다. 기존 프로젝트와 저장한 MP4를 보존했다.

메모리는 앱과 자식 프로세스의 동시 RSS 합이며 시험 드라이버는 제외했다. 저장·프로젝트·취소 단계도 포함한다. 원시 표본 간격은 완료 실행 단계에서 최대 290.54ms였다. 각 실행의 복원·설정·재생 조작을 각각 32회 측정했다. 네이티브 파일 선택·저장 경로는 시험 도구가 지정했으므로 실제 OS 대화상자 조작의 증거와 구분한다.

## 판정 범위와 남은 검증

제품·번들·패키지·측정 소스 347개 파일의 해시를 고정하고 warm 12회, cold 12회를 순차 실행했다. 각 묶음 뒤 파일 집합과 해시를 확인하고 실제 결과를 감사했다. 고정 파일 검사 도구는 정상 명세 허용, 해시 변조 거부, 파일 항목 누락 거부의 세 대조를 통과했다. 대조는 명세 사본으로 수행했으며 제품 파일을 바꾸지 않았다.

현재 후보의 **기본 무음 장시간 행렬 24/24회와 취소·재시도 8조건을 완료·감사**했다. 최대 합산 RSS는 약 1.933GiB로 2GiB 기준 이내다. 별도 60초 8회는 장시간 횟수에 더하지 않는다. 이전 `86a5c4d`와 그 이전 후보의 성능 기록·실패는 각각 보존하며 이 후보의 횟수에 합산하지 않는다.

이 판정은 기본 음량 모드의 두 앱·두 입력 파일 캐시 조건에 한정한다. 실제 한국어 발화·작업 시간, 현재 후보의 자막·효과음 장시간 합성, 인증된 AI 연결, 다른 Mac의 설치와 OS 네트워크 차단은 별도 검증 대상이다. 정식 MVP 전체 완료를 의미하지 않는다.

# 프로젝트 교정 용어 실행 기록

실행일: 2026-09-05. 기준 커밋 `1ab12be` 이후 이 문서와 함께 추가한 작업 트리에서 [용어 계획](../plans/2026-09-05-project-glossary-plan.md)을 구현·검증했다. 실제 인증된 모델은 호출하지 않았다.

## 구현과 저장 범위

자막 창에서 프로젝트별 교정 용어를 최대 2,000자 입력하고 적용한다. 자막·스타일과 같은 실행 취소 이력에 한 단계로 들어가며 프로젝트 미저장 표시가 켜진다. 용어 적용 자체는 자막 문구·시각·컷·영상 출력을 바꾸지 않는다. 적용하지 않은 문구·용어를 닫기·선택 이동·실행 취소로 버리려면 확인한다. 브라우저 새로고침과 Mac 창 닫기에도 미적용 입력 보호가 동작한다. 같은 자막을 다시 선택해 입력 폐기를 승인해도 실제 입력 필드를 초기화하도록 보완했다.

프로젝트는 v6이며 `glossary` 문자열을 포함한다. v1~v5는 빈 문자열로 이전한다. v6의 필드 누락·잘못된 타입·2,000자 초과·제어 문자는 거부한다. 줄바꿈·탭과 빈 문자열은 허용한다. 기존 저장 파일을 새로 쓰지 않으며 사용자가 저장할 때 v6를 만든다. 구버전 앱에서는 v6를 열지 못할 수 있다.

AI 교정 창은 저장된 프로젝트 용어를 기본으로 채운다. 여기서 수정하거나 비우는 것은 이번 요청에만 반영되며 프로젝트 값을 덮어쓰지 않는다. 프로젝트 값으로 복귀하는 버튼도 있다. 용어 변경은 준비된 요청과 제안을 무효화하며 새 요청 ID를 사용해야 한다. 용어 저장·복사·연결 설정만으로 모델을 호출하지 않는다. 명시적 교정 요청은 선택한 자막과 현재 보이는 요청용 용어만 보낸다. 새 영상·다른 프로젝트로 이동하면 이전 용어와 이력을 넘겨주지 않는다.

## 실제 앱 검사

[원본 결과 JSON](results/2026-09-05-project-glossary-ui.json)에 Chrome와 패키지 Mac 앱 각각의 결과가 있다. 두 앱 모두 용어 입력·적용·실행 취소/다시 실행, 미적용 입력 폐기/유지, 저장된 프로젝트만 있는 상태에서 미적용 용어의 창 보호, 요청용 임시 변경/비우기/프로젝트 값 복귀, 오래된 제안 거부, 저장/재열기, 손상된 프로젝트 거부 후 기존 편집 보존, 새 영상 초기화를 통과했다.

자막 문구·시각·컷·스타일·효과음은 저장 전후 동일했다. 준비·저장 단계의 모델 요청은 0건이며, 명시적으로 누른 요청 1건은 임시 로컬 UI 응답으로 가로채 전송값만 검사했다. 실제 모델 추론·사용량은 검사하지 않았다. 두 앱의 페이지 오류와 외부 브라우저 요청은 각각 0건이었다. 390px Chrome 화면의 가로 넘침도 없었고 Chrome·Mac·390px 캡처를 열어 확인했다. 이미지와 로그는 로컬 `test-output/glossary-*`에 있다.

Mac 창 닫기의 첫 자동 검사에서는 Electron의 네이티브 확인창과 Playwright의 자동 CDP 처리가 중복되어 `No dialog is showing` 오류로 중단됐다. 네이티브 창 검사의 관찰 중에는 CDP에서 추가 응답하지 않도록 테스트를 수정했다. 최종 실행은 네이티브 확인창이 호출되고 창이 닫히지 않으며 입력이 유지되는 것까지 통과했다. 임시 앱 프로세스가 남지 않았음을 확인했다.

## 남은 판정

이 결과는 실제 한국어 녹음에서 용어가 정확히 반영되는지, 오타가 줄어드는지의 품질 통과가 아니다. 전사 엔진용 사전·자동 치환·전역 공유 사전을 추가하지 않았다. 실제 인증 모델별 교정/효과음 배치, 대표 한국어 영상의 발화 보존·작업 시간, 긴 VAD/STT/자막·효과음 출력 성능, 남은 OS 복구 사례와 ChatGPT 직접 통합은 계속 미완료다. Mac 패키지는 서명·공증되지 않았고 설치된 FFmpeg/ffprobe가 필요하다.

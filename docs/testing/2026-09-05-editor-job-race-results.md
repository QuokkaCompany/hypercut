# 편집창별 취소 재시도와 새 원본 보존

실행일: 2026-09-05 America/New_York. `1bb0057`에서 자막 창의 취소 재시도 문제를 재현하고 이번 수정의 브라우저 번들과 Mac 패키지를 검증했다. [계획](../plans/2026-09-05-editor-job-race-plan.md), [수정 전 4회](results/2026-09-05-editor-job-races-before.json), [수정 후 34회](results/2026-09-05-editor-job-races-after.json), [일반 편집 회귀](results/2026-09-05-editor-job-races-regressions.json)를 연결한다.

## 재현과 수정

전사 또는 SRT 생성 중 취소 요청이 실패하면 내부의 취소 요청 표시는 해제됐지만 진행 문구는 ‘취소 중’으로 남았다. 자막 창은 이 문구를 기준으로 취소 버튼을 비활성화하므로 다음 작업 조회 응답이 오기 전에는 창 안에서 재시도할 수 없었다. 메인 화면의 취소 버튼은 같은 비활성화 조건을 사용하지 않아 앞선 기본 경합 검사에서 발견하지 못했다.

실제 전사·SRT 완료 조회 응답을 대기시키고 현재 취소 요청만 503으로 실패시켰다. Chrome와 Mac의 두 작업, **4회 모두 자막 창 취소 버튼이 계속 비활성화되는 상태를 재현**했다. 조회 응답이 정상 도착하면 상태가 다시 바뀔 수 있으므로 영구적인 작업 소실로 표현하지 않는다.

현재 작업의 취소 실패를 처리할 때 진행 문구를 ‘취소 요청 실패 · 다시 시도해 주세요’로 갱신했다. 자막 창에서 버튼이 다시 활성화되고 재시도가 가능하다. 이전 작업의 늦은 오류를 무시하는 작업 객체·순서 검사도 유지한다.

새 **20회 모두 PASS**이며 앞선 기본 경합 **14회도 PASS**다. 이번 실행의 합계는 34회다. 전사는 한국어 Eddy TTS 영상과 실제 Whisper small을 사용했고, 전사 분기의 6회 모두 실제 결과 2개 자막을 관측했다. 실제 녹음 정확도 수치로 사용하지 않는다.

SRT 취소는 자막 창 안에서, 일반 전사 경합은 전사 중 자막 창을 닫아 메인 화면으로 돌아온 상태에서 수행했다. 새 영상 열기는 작업 중 비활성 상태이고 취소가 정리된 뒤에만 허용됐다. 재시도 조건에서는 실패 직후 자막 창 버튼이 활성화되고 실제 DELETE 요청이 두 번 발생했는지 확인했다.

이전 응답을 해제할 때 B의 새 미리보기 요청을 대기시켜 원본·컷·-42dBFS·미저장 표시·진행 작업·출력 버튼의 상태가 유지되는지 비교했다. 이어 B의 실제 미리보기를 완료하고 새 결과 ID가 B의 작업에 속하는지 확인했다. 효과음 조건에는 실제 생성한 WAV를 연결해 A와 B에 서로 다른 시각·음량으로 배치했으며, 두 결과에서 효과음 1개가 합성됐는지 확인했다.

마지막 프로젝트를 실제 저장하고 저장 시각을 제외한 모든 필드를 정답과 비교했다. 전사·스타일·용어·효과음 데이터도 포함한다. 모든 조건에서 예기치 않은 브라우저 다운로드와 Mac 저장 호출은 0회였다. 두 영상과 효과음 원본의 해시가 유지됐고, 페이지 오류·관측한 외부 브라우저 요청도 0건이었다.

## 판정 범위와 실행

이번에는 공통 작업 처리의 전사·SRT·부분 복원·효과음 미리보기 분기와 새 원본의 경합을 확인했다. 이전 [기본 경합](2026-09-05-job-cancellation-race-results.md)의 미실행 표시 중 해당 분기를 보완한다. **비동기 효과음 파일 불러오기와 이미 시작한 프로젝트 파일 읽기가 교차하는 경로**는 이 시험에 포함하지 않았다. 이를 포함한 모든 파일 가져오기 경합이나 E06 전체의 완료로 넓혀 표시하지 않는다.

네이티브 파일 창 경로는 시험이 지정했다. 취소한 HTTP 요청의 `fulfill-resolved`는 앱이 본문을 소비했다는 뜻이 아니며, 실제 JSON 읽기 완료를 확인한 늦은 취소 응답과 구분한다. 이번 취소 재시도는 서버 처리가 완료됐지만 UI가 완료를 받기 전인 상태의 검사다. 별도 프로세스 강제 종료·네트워크 차단·실제 녹음 품질·인증된 LLM 요청 검증을 대체하지 않는다.

```sh
npm run test:jobs:races -- --output=test-output/새-시험-이름
```

현재 기본 실행은 두 앱의 34조건을 포함하므로 Mac 패키지, 로컬 Whisper 모델, 한국어 Eddy TTS와 FFmpeg가 필요하다. 재시도 재현만 실행하려면 `--scenarios=CURRENT_CANCEL_ERROR_TRANSCRIBE,CURRENT_CANCEL_ERROR_CAPTIONS`를 추가한다. 기존 결과 폴더를 덮어쓰지 않는다.

# Interactive HyperCut landing page

An English promotional page at `/landing.html`, independent of the editor entry point. Use the existing lime H identity, warm paper background, bold typography and a dark interactive timeline. The hero introduces silence-first editing for tutorials, lectures and talking-head videos.

The timeline is an explicitly illustrative, deterministic sample: threshold changes remove quiet spans, clicking a cut restores it, original/edited views and a visual playhead demonstrate the effect. It never uploads media or presents simulated analysis as live AI processing. A caption-style selector previews three visual treatments. Real existing screen recordings open in an accessible dialog with their silent/generated-sample provenance visible.

Local and self-hosted installation tabs provide accurate copyable commands and links to the repository. The current early-development and Korean-editor status are visible. No invented download, hosted SaaS, testimonials, adoption metrics or accuracy claims.

Use React and existing lucide icons, isolated CSS, local assets, responsive layouts, keyboard-accessible controls, reduced-motion support, modal focus management and meaningful Playwright checks. Build both editor and landing entries with Vite; add a standalone landing build for future static hosting. Publishing to an external host is outside this request.

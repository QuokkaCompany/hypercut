# Community guidelines

We want HyperCut to be a place where people with different backgrounds and levels of experience can collaborate productively.

- Be respectful and specific. Critique ideas and code without attacking people.
- Assume good faith, explain your reasoning, and welcome questions and corrections.
- Avoid harassment, threats, discriminatory language, sexualized conduct, and unwanted contact.
- Respect privacy. Do not publish someone else's personal information, private messages, credentials, or recordings.
- Keep discussion relevant and avoid spam or disruptive promotion.

Maintainers may edit or remove inappropriate content, close disruptive discussions, restrict participation, or block accounts. They should apply these guidelines consistently and explain moderation decisions when doing so does not expose private information.

Report abusive content using GitHub's reporting tools. For an ordinary moderation request, contact a maintainer through an available private GitHub channel; if none is available, open an issue requesting a private contact method without naming people or disclosing sensitive details. Security vulnerabilities should follow [SECURITY.md](SECURITY.md).

These guidelines apply in repository issues, pull requests, discussions, and other official project spaces.
